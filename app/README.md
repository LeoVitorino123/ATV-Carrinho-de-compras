# Calculadora de Carrinho de Compras

**Aluno:** Leonardo Vitorino

App Android (Jetpack Compose + Material 3) que carrega um catálogo fixo, aplica descontos,
lista o carrinho com um componente reutilizável e gera relatório no Logcat (tag `CARRINHO`).
